# Updating KhulnaSoft Projects

When a change to KhulnaSoft UI is made, it will not be reflected in other projects until the package is
updated. We use [Renovate KhulnaSoft Bot](https://khulnasoft.com/khulnasoft-org/frontend/renovate-khulnasoft-bot) to
automate dependency updates of `@khulnasoft/ui`.

To update the `@khulnasoft/ui` dependency of KhulnaSoft locally for development, see [KhulnaSoft integration](contributing/khulnasoft_integration_test.md).
